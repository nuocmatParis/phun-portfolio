# Tran Phu Hung Portfolio

Personal portfolio website for Tran Phu Hung, a backend developer focused on Java, Spring Boot, REST APIs, security, payments, and real-time systems.

## Features

- English, Japanese, and Vietnamese content
- Animated light and dark theme switching
- Responsive home, about, and projects pages
- Downloadable CV
- Project and certification highlights

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run check
```

This runs ESLint, TypeScript checking, and a production build.
