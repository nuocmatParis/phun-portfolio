# Component Inventory

1. `SiteNavigation`: fixed desktop header, fixed mobile bottom navigation, route pills, theme toggle, and scroll state.
2. `IdentityCard`: status badge, animated availability dot, name, title, separator, and handle.
3. `BioCard`: section label and verbatim biography copy.
4. `SocialLinksCard`: four square external-link controls using extracted SVGs.
5. `SkillsMarquee`: duplicated skills groups inside a masked, pausable marquee.
6. `SiteFooter`: desktop-only copyright divider and text.

All visual content is HTML, CSS, text, or inline SVG. The target has no `<img>`, background-image, video, canvas, or Lottie content.
